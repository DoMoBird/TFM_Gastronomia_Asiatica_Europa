Semana 1 — Carga y primera exploración

NotebookContenido
01_carga_exploracion (.ipynb) Descarga del dataset de Kaggle, carga con pandas, filtrado de restaurantes asiáticos (86.306 de 1.083.397), primera exploración (shape, tipos, nulos).

Semana 2 — Análisis Exploratorio de Datos (EDA)

NotebookContenido
02_eda (.ipynb) Distribución geográfica, tipos de cocina por país, mapa interactivo, análisis de valoraciones y reseñas, matriz de correlación.
02b_tendencia_buffet_asiatico (.ipynb) Análisis complementario: tendencia de los restaurantes tipo buffet libre asiático, con discusión explícita de las limitaciones temporales del dataset y búsqueda de fuentes más recientes.
mapa_restaurantes_asiaticos.html Mapa interactivo (Plotly) con la geolocalización de los 86.306 restaurantes asiáticos.

Semana 3 — Preprocesamiento y primeros modelos

NotebookContenido
03_preprocesamiento_modelos (.ipynb) Limpieza de datos, feature engineering, train/test split, y comparativa de 4 modelos (Regresión Lineal, Random Forest, XGBoost, SVR) entrenados en el entorno principal.
03b_red_densa_keras (.ipynb) Quinto modelo (red densa / MLP con Keras), entrenado en un entorno virtual aislado (tfm-tf) por incompatibilidad de TensorFlow con el entorno principal — ver nota técnica más abajo.

Semana 4 — Modelización avanzada

NotebookContenido
04_modelizacion_avanzada (.ipynb) Ajuste de hiperparámetros de XGBoost (RandomizedSearchCV), validación cruzada, interpretabilidad con SHAP, y productivización (función predict_rating() + modelo guardado con joblib).
Nota técnica — entorno de TensorFlow: el notebook 03b_red_densa_keras se ejecuta con un kernel de Python distinto al resto (entorno virtual .venv_tf), porque TensorFlow provocaba un segmentation fault al importarse en el entorno base usado en el resto del proyecto (conflicto de versión de protobuf con otros paquetes ya instalados). Para no arriesgar la estabilidad del entorno principal se aisló en un venv propio. Los resultados (RMSE/MAE/R²) se exportan a data/dense_nn_metrics.json y se cargan desde el notebook principal (03_preprocesamiento_modelos) para la tabla comparativa. Para reproducir este notebook: python3 -m venv .venv_tf && source .venv_tf/bin/activate && pip install tensorflow pandas numpy scikit-learn matplotlib ipykernel.
