Valoración de restaurantes asiáticos

Demostrador académico · Peng Chen

Estima la valoración de un restaurante existente a partir de sus características. El modelo se ha evaluado sobre una fotografía histórica de 2021. No predice ventas, rentabilidad ni el éxito de una nueva apertura.

País y región deben corresponder a los datos observados. Los campos vacíos se consideran desconocidos; no se inventa una ubicación por defecto. En cocina, 1 significa etiqueta presente y 0 etiqueta no registrada.

Introduce las características o carga el ejemplo.

El error medio del test es una medida agregada, no un intervalo de confianza para este restaurante.
